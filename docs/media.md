# Screenshots and GIFs

The repository does not ship recordings yet. To add one:

1. Open `examples/basic-typescript` in VS Code with Better Live Coding installed.
2. Run *Start Presentation Mode* (accept creating `practice/`).
3. Record the editor window (for example with ScreenToGif, Kap or the OS recorder) while pressing Enter for two or
   three steps, so that the status bar (`Stage 1 · Step 2/3`, `Thinking · …`), a file switch and an IntelliSense popup
   are visible.
4. Save the GIF as `docs/media/demo.gif` (keep it under 5 MB) and reference it from both READMEs.

Make sure the recording shows no personal paths, account names, tokens or notifications.
